## 4. 开发与复查中修正

- `0.3.0a2` 补充回退前的旧版本/配置/时间检查、完整旧 manifest 和 marker 证据、禁止凭据可见输入降级、候选目标隔离和包路径冲突检查；新增 Basic/Core 同时包含两种历史 schema 的导入与下一周期重复触发回归。
- 计划、应用和回退不再依赖单一 service inactive 判断，分别核对 timer、排队任务、来源和文件；始终保留暂停/失败的真实阶段。
- r2 退役守卫使用 `/var/lib` 受保护证据副本校验早期来源，避免 systemd `ProtectHome=true` 下依赖 `/root` 原备份。
- 旧 unit 先归档后 mask 的中断间隙纳入已知回退状态；备份未完成且正式文件未动时允许撤销意图，不凭空要求完整备份。
- 迁移后的后续进程重新加载退役证据，升级/凭据操作只备份本次可变目标，保留最初 r2 来源。
- 安装与到额恢复分开：新安装须可用；保持既有配置的迁移/升级/凭据轮换按逐对象恢复策略接受到额等待，不提前恢复或清零。
- 发行包附带合成验证材料，使 README/契约中的链接与本地复现入口在包内闭合。包 SHA 保存在独立 sidecar，不嵌入包内文档造成自引用 hash。

开发初轮模拟曾因未模拟 bootstrap 目录和 Windows 路径分隔符比较失败，已修正测试设施；没有修改生产契约来绕过测试。包链接检查初版误把有效目录链接当成缺失文件，已按包内文件前缀辨认目录后重验。失败日志/预览包留在忽略目录用于追踪，不覆盖最终包。
