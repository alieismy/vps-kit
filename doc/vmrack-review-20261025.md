## 重点契约核对

| 范围 | 核对结论与边界 |
|---|---|
| 固定锚点 / 每日唤醒 | `A+n×2592000`、n≥0；日唤醒只触发资格判断，非账期零面板 API/零控制日志追加。漏期、不确定历史不补跑；时钟跳变、NTP 和实际发送前写窗口仍阻断。 |
| VMISS 月日历 | v1 配置及历史摘要保持；Basic/Core Toronto 月日历不改每日唤醒；DST/短月和配置切换不得缩短授权周期的原测试保留。 |
| M1 / M2 / 首期再确认 | M1 按全部对象的实际/可能副作用证据检查旧 300 秒窗口及商家网格；M2 用实际 cutover 重新计算，延期必须同 operation_id 再确认。等待阶段不产生运行授权；failed 不自动重试。 |
| 双锁 / 持续退役 | 来源类型仍决定固定旧路径，新锁→旧锁；原生与两类迁移来源均执行通用锁身份检查。stub、实际 mask、已登记 cron、源文件及备份漂移阻断。 |
| 多 Client / 到额恢复 | 1—16 个 Client、独立配额/策略与父池；父池满不能代替 Client 本人满额；hold 不清零，stop 不恢复禁用对象，quota-recovery 仅恢复获准满额对象。两个官方版本的原反例和 16 Client 场景保留。 |
| 防重复清零 | durable pending 在 POST 前；每步最多发起一次；响应丢失、读回/持久化失败及锁身份变化后不重放。不是服务端 exactly-once，整机一致回卷仍需外部证据。 |
| 回退 | 最近操作、owner/revision/格式资格、备份和全部来源先核查；暂停后再核查。只回文件，不回历史/计数，不启用旧脚本；后续新版执行账本存在时拒绝不兼容格式降级。 |
| 凭据 / traffic.2 | Token 不进 argv、报告或计划明文；旧证明运行期使用受保护备份，初始迁移文件退出仍需原件。`3.7.0+traffic.2` 不剥离后缀放行，写适配延期。 |
